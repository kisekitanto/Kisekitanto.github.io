🛠 How to create a build yourself (click to expand)
  1. Open project in Godot 4.7
  2. Project → Export → Click Add... → Choose Windows Desktop
  3. Configure: Embed PCK = ON (single .exe), Texture Compression = VRAM (faster load)
  4. Click Export Project → Save as UnnamedRPG.exe
  5. Test it runs, then zip it: UnnamedRPG_v0.1.0.zip
  6. Go to GitHub repo → Releases → Create a new release → Tag v0.1.0 → Upload zip
  7. Update the href on the download button above to point to that release

Pro tip: Add a CHANGELOG.md to the repo and reference it in the release notes.

How I Got Here

Dev timeline (the honest version)

From "what's a variable?" to "why is my biome blending creating artifacts at chunk boundaries?"

April 2024

Downloaded Godot for the first time

Thought "2D can't be that hard." Famous last words. Spent week one fighting the camera and wondering why my player walked through walls.

July 2024

First working state machine

Idle → Walk → Run with proper transitions. Learned what "normalized diagonals" means the hard way (player moved faster diagonally for 3 months).

October 2024

Discovered TileMapLayers & autotiles

Stopped placing tiles one by one like a caveman. Terrain sets + bitmasks = actual level design workflow. Also found Dialogic and stopped hardcoding dialogue in JSON.

January 2025

Procedural generation rabbit hole

Started with "I want infinite worlds." Ended up researching Perlin noise, voronoi diagrams, and why my beaches kept spawning in the middle of forests. Gaea entered the chat.

July 2025

Scope creep: the project

Went from "simple RPG" to "biome blending with real geographic logic, stamina combat with 3 damage types, reverb zones, footstep variation by surface." The story is still the same though.

October 2026

Right now

Debugging := type inference errors, fighting file corruption from automated tools, learning to implement features manually with precise instructions. Also built this portfolio. Hi.
